# API Testing Project

## Project Overview
This project contains API testing practice using Postman and ReqRes API.

## API Testing Performed
- Login Request Validation
- Invalid Data Testing
- Empty Request Testing
- Authentication Validation
- Response Validation

## Tools Used
- Postman
- ReqRes API

## Deliverables
- API Request Testing
- Response Validation
- Error Handling Validation
- Screenshots
